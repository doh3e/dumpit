- 수집 항목 (모두 "공유 안 함", 처리 목적 = 앱 기능·계정 관리):

| 카테고리 | 항목 | 필수 여부 |

## 8. 업로드 순서 (계정 승인 후)

1. 앱 만들기: 이름 `덤핏`, 기본 언어 한국어, 앱(게임 아님), 무료
2. 대시보드 "앱 설정" 설문 전부 완료 (5~7절 답 그대로)
3. 스토어 등록정보: 2~4절 입력
4. **비공개 테스트** 트랙 생성 → production AAB 업로드 (versionCode 5, EAS 빌드 da528ef6)
5. 업로드 후: 설정 → 앱 무결성에서 **Play App Signing SHA-1 확인 → Google Cloud 콘솔 Android OAuth 클라이언트에 추가** (안 하면 스토어 배포본 구글 로그인 실패)
6. 테스터 명단(외부 업체) 등록 → 14일 연속 테스트 → production 신청
7. (병행) 스크린샷 촬영·업로드, 심사용 테스트 계정 준비
